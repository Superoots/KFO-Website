# Kieferorthopädie Übersee – Modern Website

Modern, white-mode website for **Kieferorthopädische Fachpraxis Dimitrios Mavroeidakos** in Übersee am Chiemsee.

## Tech Stack
Plain HTML5, CSS3, vanilla JavaScript — no build step required.

## Local Development
Open `index.html` in a browser or run `npx serve .`

## Deployment
Push to GitHub → Settings → Pages → main branch, root `/`
